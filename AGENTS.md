# Orientações do repositório

Este é o repositório geral do projeto, não apenas da aplicação web.

- Mantenha o código e a configuração do site dentro de `site/`.
- Mantenha estratégias, propostas, apresentações, PDFs e ideias dentro de `docs/`, organizados pela área correspondente.
- Siga `site/AGENTS.md` para alterações dentro da aplicação web.
- Consulte o `README.md` da pasta de documentação correspondente antes de adicionar materiais a `docs/`.
