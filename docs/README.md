# Documentação e materiais do projeto

Use esta pasta para documentos que atendem ao projeto como um todo. Organize cada arquivo por assunto:

- [`estrategia-comercial/`](estrategia-comercial/): estratégia, canais, posicionamento e plano comercial.
- [`propostas/`](propostas/): propostas e versões para clientes ou parceiros.
- [`apresentacoes/`](apresentacoes/): apresentações do projeto e seus arquivos exportados, como PDFs.
- [`ideias/`](ideias/): ideias e hipóteses ainda em avaliação.

Guarde o PDF junto dos arquivos editáveis e materiais do mesmo assunto, usando nomes claros e datas quando houver versões.
