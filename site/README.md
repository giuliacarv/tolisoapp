# Aplicação web

Esta pasta contém o site e o webapp do projeto, incluindo código, recursos, configuração e testes. A aplicação foi originalmente criada no Lovable.

## Desenvolvimento local

Com o Bun instalado, a partir da raiz do repositório:

```sh
cd site
bun install
bun run dev
```

O projeto usa React, TypeScript, TanStack Start e Vite. Consulte `AGENTS.md` nesta pasta para as orientações específicas da integração existente.

## Aplicação publicada

URL registrada para a versão atual: [tolisoapp.lovable.app](https://tolisoapp.lovable.app).
